# Construction Enterprise OS

建設・土木プロジェクトの進捗、原価、安全、図面、写真、承認、監査証跡をひとつの画面で確認するための統合業務基盤です。

このREADMEは、次の方が短時間で全体像を理解できるように、専門用語をできるだけ使わずに整理しています。

- 本社・支店の管理部門
- 現場所属の施工管理者
- 土木建設技術者・研究者
- 経営役員
- 監査法人・内部監査担当

IT部門、開発者、詳細な技術構成を確認したい方は、下記の「関連ドキュメント」を参照してください。

## ひとことでいうと

Construction Enterprise OS は、建設会社の本社・支店・現場・協力会社・監査対応を、同じ情報基盤でつなぐための業務OSです。

現場の日報、写真、図面、承認、IoTアラート、原価、工程、監査ログを分断せず、関係者が同じ前提で確認できる状態を目指します。

## 現在のWebUI

現在は、実データ接続前のモック環境です。画面の流れ、情報量、利用者別の見え方を確認しやすいように、多めのダミーデータを入れています。

この環境で確認済みのURL:

```text
http://192.168.0.185:3102/
```

機器再起動時やポート競合時は、空いているポートが自動選択されるため、URLの末尾番号が変わる場合があります。

## WebUIで確認できること

| 領域 | 画面で分かること |
| --- | --- |
| 全社ダッシュボード | 工事全体の進捗、原価、安全、承認待ち、リスク |
| 現場管理 | 日報、出来高、写真、作業予定、KY、安全巡視 |
| 図面・文書 | PDF、CAD、BIM/CIM、写真、動画、電子納品、版管理 |
| 承認・稟議 | 承認待ち、変更申請、電子署名、決裁の滞留 |
| 原価・予算 | 予算、契約、発注、請求、労務、在庫、経営指標 |
| GIS・地図 | 工事位置、災害リスク、ドローン、点群、ハザード情報 |
| IoT | センサー、気象、波浪、水位、ゲートウェイ、アラート |
| AI | チャット、ナレッジ検索、OCR、画像判定、予測、異常検知 |
| セキュリティ | 監査ログ、SOC、VPN、端末防御、インシデント |
| ロボティクス | 自律施工、ドローン、ROV、デジタルツイン |

## 利用者別の見方

| 対象者 | 主な確認ポイント |
| --- | --- |
| 現場施工管理者 | 今日の作業、写真、日報、承認待ち、安全アラート、機材稼働 |
| 土木建設技術者・研究者 | BIM/CIM、GIS、IoT、AI解析、施工データの蓄積状況 |
| 本社・支店管理者 | 工事横断の進捗、原価見通し、支店別の負荷、承認滞留 |
| 経営役員 | 売上・原価・利益見通し、重大リスク、投資判断、全社KPI |
| 監査法人・内部監査 | 承認履歴、操作ログ、証跡、文書版管理、電子納品の欠落有無 |

## 想定される活用場面

- 朝礼前に、現場の安全・作業・承認状況を確認する。
- 支店会議で、複数工事の工程遅延と原価リスクを比較する。
- 経営会議で、全社の進捗、利益見通し、重大リスクを確認する。
- 監査対応で、承認履歴、文書版管理、操作ログをたどる。
- 研究・技術検証で、GIS、IoT、AI、BIM/CIMの連携イメージを確認する。

## 現在の状態

このリポジトリでは、WebUIモック、Docker起動、systemd登録、起動時の自動ポート割当を確認済みです。

- WebUIはダミーデータ中心のモック画面です。
- 実在する工事名、個人名、金額、センサー値ではありません。
- 本番利用には、実データ連携、権限設計、監査要件、セキュリティ設定の確認が必要です。
- Dockerとsystemdにより、機器起動時にWebUIを自動起動できます。
