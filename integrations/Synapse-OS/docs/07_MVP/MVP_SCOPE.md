# MVP_SCOPE

## 目的

MVP Scope は、AI Native Enterprise OSの最初の実証範囲を、巨大化させずにEnterprise OSの核へ絞る。

## MVP対象

| MVP | 理由 |
|---|---|
| Issue + Approval | 日本企業文化とWorkflowの中心 |
| AI Audit | AI統制の最小核 |
| Document Governance | DLPとEnterprise Knowledgeの入口 |
| Federation Auth | A社/B社/C社モデルの実証 |
| Teams / Mail Integration | 実務導線の入口 |

## MVP非対象

| 非対象 | 理由 |
|---|---|
| ERP全機能 | 巨大化する |
| 完全ITSM | Scopeが広すぎる |
| 全社Knowledge Graph | 初期から重い |
| 自律AI実行 | Governance検証後に拡張 |
| 完全Federation Workflow | まず認証とAuditから |

## MVP成功条件

- IssueからApprovalが起票できる
- AI利用がGateway経由でAuditされる
- 文書にClassificationとDLP判定が付く
- A社/B社/C社のTenant境界が表現できる
- Teams/MailからIssue化できる
