# 利用者マニュアル（現場向け）

> 対象: 現場監督・土木技術者・協力会社・資材担当者
> 最終更新: 2026-08-12

本書は、土木・建設現場で `MaterialPhotoLogger`（以下「本アプリ」）を使う方へ向けた操作手順です。
本アプリは**完全オフライン**で動作し、記録した写真・入力内容は**端末内にのみ保存**されます。

---

## 1. 本アプリでできること

| 機能 | 説明 |
|---|---|
| 写真撮影 | カメラで材料を撮影し、その場で記録（複数枚・手書き注釈・GPS・日時付き） |
| 情報入力 | 案件番号・材料名・区分・数量・単位・置場・メモ・取引種別（搬入/使用/返却） |
| 一覧・検索 | 保存済み記録を新しい順に表示。キーワード・案件・区分・置場・期間で絞り込み |
| 台帳出力 | CSV（Excel用）・JSON・PDF写真台帳・案件比較データを書き出し・共有 |
| QR / OCR | 案件番号QRや伝票・ラベルの文字を読み取って入力補助 |
| バックアップ | 記録と写真を1ファイルにまとめ、機種変更・端末故障に備える |

---

## 2. インストール（TestFlight）

1. App Store から「TestFlight」をインストールする。
2. 開発担当から届いた招待メールのリンクを開く。
3. TestFlight アプリ内で本アプリをインストールする。

> 配布方法は会社の指示に従ってください。一般公開（App Store）になった場合は、通常のアプリと同様にインストールできます。

---

## 3. 基本操作（4ステップ）

### ステップ1: ホーム画面から「写真を撮る」をタップ

カメラが起動します。材料全体が写るように撮影してください。
撮影後、写真の上に丸・矢印・文字などの注釈を手書きで追加できます（不要ならそのまま次へ）。

### ステップ2: 材料情報を入力

**必須項目**（案件番号・材料名）を入力します。それ以外は任意です。

| 項目 | 入力のヒント |
|---|---|
| 案件番号 | 過去に入力した案件番号は候補として表示されます |
| 材料名 | 同じく候補表示あり。QR読み取りやOCRで自動入力も可能 |
| 材料区分 | 仮設材・構造部材・土木材料・安全用品・リース品・その他 |
| 数量・単位 | +1/−1ボタンでクイック入力。小数にも対応 |
| 置場 | 第1資材置場・A工区など、あとで探しやすい名称を推奨 |
| メモ | 破損・概算・返却予定などの補足（500文字以内） |
| 取引種別 | 搬入（入ってきた）・使用（現場で使った）・返却（帰す） |
| 検収ステータス | 未検収・検収済・差し戻し（詳細画面から変更） |

### ステップ3: 「一時保存」をタップ

必須項目が未入力の場合はエラーが表示され、該当欄が開きます。
保存が完了すると一覧に反映されます。

### ステップ4: 一覧で確認・書き出し

- 一覧画面から記録をタップすると詳細が確認できます。
- 詳細画面から「編集」「複製」「削除」「共有」ができます。
- ホーム画面または一覧画面から **CSV出力** を選ぶと、Excelで開ける台帳が生成されます。

## 4. 現場で便利な機能

### 4.1 QRコード読み取り

案件番号などのQRコードを読み取ると、案件番号・材料名が入力欄へ反映されます。
読み取り結果は必ず表示確認してから使用してください。

### 4.2 OCR（文字認識）

納品書・伝票・ラベルを撮影すると、文字が認識されます。
**認識結果は自動で保存されません**。候補から入力先を選んで反映します。
誤認識のまま保存しないよう、保存前に必ず確認してください。

### 4.3 手書き注釈

撮影直後のプレビューで、写真に丸・矢印などを書き込めます。
注釈は写真と一体化して保存されます（元の写真は変更されません）。

### 4.4 GPS（撮影場所）

位置情報を許可すると、撮影場所（緯度・経度）が記録されます。
位置情報を許可しなくても、写真撮影・保存は利用できます。
一度拒否した場合は、端末の「設定」アプリから許可できます。

## 5. バックアップと機種変更

本アプリのデータは**端末内のみ**にあります。
端末の故障・紛失・アプリ削除でデータが消えるため、**月に1回以上のバックアップ**を推奨します。

### バックアップを作成

1. 設定画面を開く。
2. 「端末間バックアップ」→「バックアップを作成」をタップ。
3. 共有画面が開くので、会社指定の共有先（メール・クラウドストレージ等）へ保存。

### バックアップから復元（機種変更時）

1. 新しい端末に本アプリをインストール。
2. 設定画面 →「バックアップから復元」をタップ。
3. バックアップファイルを選択すると、記録と写真が復元されます。

> 復元は既存データへの「上書き・追加」です。同一IDの記録は上書き、それ以外は追加されます。

---

## 6. 注意事項

- **アプリを削除すると端末内の全記録・写真が消えます。** 削除前に必ずバックアップを取ってください。
- 本アプリはデータを外部送信しません。CSV・PDF・バックアップは、あなたが共有操作をしたときだけ端末外へ出ます。
- 写真や入力内容には、現場の安全管理情報・個人情報が写り込む場合があります。共有する際は内容を確認してください。
- 電波のない場所でも記録・保存・確認は動作します。
- 一時的に保存できない場所（端末の異常時）で動作している場合は、画面上部に警告が常時表示されます。その状態では記録を追加しないでください。

## 7. よくある質問（FAQ）

| 質問 | 回答 |
|---|---|
| 案件番号が分からない | 現場監督または会社の指定する案件番号体系を確認してください |
| 数量を間違えて保存した | 一覧→詳細→編集で修正できます。増減履歴は取引種別で管理されます |
| 写真を追加したい | 編集画面から撮影済み記録に写真を追加できます |
| 間違えて記録を消した | 端末内の削除は戻せません。バックアップがあれば復元できます |
| 他社（協力会社）と共有したい | バックアップファイル・CSV・PDFを会社のルールに従って共有してください。クラウド同期機能は現状ありません |
| アプリが反応しない | アプリを一度終了して再起動してください。再発する場合は開発担当へ報告 |
| 画面に警告バナーが出ている | 内容を確認し、可能ならスクリーンショットを添えて開発担当へ連絡してください |

---

## 8. 困ったときの連絡先

- 操作に関する質問: 会社のIT・DX部門（7名体制）
- 不具合・エラー: スクリーンショットと操作手順を添えて報告
- 新しい案件番号体系・材料区分の追加要望: 同じくIT・DX部門へ
