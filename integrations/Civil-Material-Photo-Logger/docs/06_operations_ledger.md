# 🗓 運用台帳（日次〜四半期）

本書は MaterialPhotoLogger の運用点検項目の正本である。
本アプリは**完全オフライン・端末内保存**のため、サーバー監視・SLI/SLO・アラート・
本番 DB バックアップは**構造的に存在しない**。その代わり、データ保全の責任は
**端末側のバックアップ運用**と**リリース品質**に集約される。ここを起点に点検する。

関連文書: `04_audit_and_backlog.md` / `05_release_runbook.md`

---

## 📌 1. 監視対象の整理（Web サービスとの対応）

| 一般的な運用項目 | 本アプリでの対応物 | 状態 |
|---|---|---|
| サーバーヘルスチェック | なし（サーバー不在） | N/A |
| エラー率・レイテンシ監視 | App Store Connect のクラッシュレポート／TestFlight フィードバック | 人間が確認 |
| DB バックアップ・RPO/RTO | アプリ内バックアップ機能（PR #84）＋ iOS 端末バックアップ | 利用者運用 |
| ログ保存とマスキング | `os.Logger`（端末内のみ・外部送信なし）。秘密・個人情報はログへ出力しない設計 | 実装済み |
| 証明書・ドメイン更新 | Apple Distribution 証明書・Provisioning Profile | 四半期点検 |
| 脆弱性・依存関係 | 外部依存ゼロ（Core は `import Foundation` のみ）。監視対象は Swift toolchain / Xcode / iOS SDK の EOL | 半期点検 |

## 🔁 2. 周期別点検表

### 日次〜随時（開発が動いている期間のみ・Claude 実施可）
| 項目 | 方法 | 判定基準 |
|---|---|---|
| CI 状態 | `gh run list` | 直近の main / open PR が全て success |
| open PR の滞留 | `gh pr list` | CI 成功のままマージ待ちが 7 日を超えたら人間へ再提示 |
| Issue 棚卸し | `gh issue list` | P0/P1 相当の新規報告がないこと |

### 週次（人間）
| 項目 | 方法 | 判定基準 |
|---|---|---|
| TestFlight クラッシュ・フィードバック確認 | App Store Connect | 新規クラッシュ 0。ある場合は Issue 起票 |
| 実機での基本動作（配布中のみ） | `05_release_runbook.md` §4 スモーク | 全項目 PASS |

### 月次（人間 + Claude）
| 項目 | 方法 | 判定基準 |
|---|---|---|
| バックアップ・復元試験 | 実機でバックアップ作成 → 別端末 or 再インストール後に復元 | 記録・写真が完全一致 |
| ストレージ使用量確認 | 設定画面の使用量表示 | 想定外の肥大（孤立写真の兆候 = 監査 G-10）がない |
| 文書と実装の整合 | README / docs を差分確認 | 乖離があれば docs PR |

### 四半期（人間）
| 項目 | 方法 | 判定基準 |
|---|---|---|
| Apple Distribution 証明書・プロファイル有効期限 | Developer Portal | 残 90 日未満なら更新 |
| Apple Developer Program 更新 | 年会費・契約状態 | 失効前に更新 |
| Xcode / iOS SDK / Swift の EOL・要求バージョン | Apple リリースノート | App Store 提出要件（最新 SDK 要求）を満たす |
| 権限棚卸し | GitHub リポジトリのコラボレーター・トークン | 最小権限を維持。不要トークンは失効 |

## 🚨 3. 障害対応（インシデント初動)

1. **事象の分類**: クラッシュ / データ消失 / 表示不良 / ビルド・配布不能
2. **データ消失の疑いがある場合を最優先**（本アプリの最重要リスク）。利用者へ
   「アプリを削除しない・再インストールしない」よう案内（削除で端末内データが消える）
3. 再現手順を Issue へ記録（P0/P1 判定は `04_audit_and_backlog.md` の基準に従う）
4. 修正は通常の PR フロー（branch → PR → CI → 人間マージ）。緊急でも main 直 push はしない
5. 配布済みビルドの差し戻しは `05_release_runbook.md` §5 に従う
