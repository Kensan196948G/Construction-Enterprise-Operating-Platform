## Summary

現状の `/admin/devices/{id}` ページはデバイス情報・ハートビート・インベントリを表示するが、
以下の機能が不足している。

## 追加機能

1. **インベントリ詳細表示** — JSON を折りたたみ/展開可能なツリー形式で表示
2. **ハートビート履歴グラフ** — 過去24時間の受信頻度をシンプルなバーチャート（pure CSS or Chart.js）
3. **ポリシー表示** — 現在適用中のポリシー設定を表形式で表示
4. **オンライン/オフライン判定** — 最後のハートビートから5分超 → 🔴 オフライン表示

## Acceptance Criteria

- [ ] インベントリ JSON が `<details>/<summary>` で折りたたみ表示
- [ ] 最終ハートビート時刻から「x分前」の相対時刻表示
- [ ] オンライン/オフライン バッジ（5分閾値）
- [ ] ポリシーセクション（`/api/v1/policy?device_id=` から取得して表示）
