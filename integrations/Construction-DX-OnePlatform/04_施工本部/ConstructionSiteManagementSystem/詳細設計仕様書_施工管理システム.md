## 2. オフライン同期設計（最重要）

### 2.1 Service Worker戦略
```javascript
// sw.js - Workbox設定
workbox.routing.registerRoute(
  /\/api\/v1\/.*/,
  new workbox.strategies.NetworkFirst({
    cacheName: 'api-cache',
    networkTimeoutSeconds: 5,
    plugins: [
      new workbox.expiration.ExpirationPlugin({
        maxEntries: 500,
        maxAgeSeconds: 7 * 24 * 60 * 60, // 7日
      }),
    ],
  })
);
```

### 2.2 IndexedDB スキーマ（Dexie.js）
```typescript
class ConstructionDB extends Dexie {
  dailyReports: Table<DailyReport>;
  photos: Table<SitePhoto>;
  progressRecords: Table<ProgressRecord>;
  costRecords: Table<CostRecord>;
  kyRecords: Table<KYRecord>;
  syncQueue: Table<SyncQueueItem>;

  constructor() {
    super('ConstructionSiteDB');
    this.version(1).stores({
      dailyReports: '++id, projectId, reportDate, syncStatus',
      photos: '++id, projectId, capturedAt, syncStatus',
      progressRecords: '++id, projectId, recordDate, syncStatus',
      costRecords: '++id, projectId, recordDate, syncStatus',
      kyRecords: '++id, projectId, recordDate, syncStatus',
      syncQueue: '++id, entityType, entityId, operation, createdAt'
    });
  }
}
```

### 2.3 同期コンフリクト解決
```
オフライン入力
     │
     ▼
IndexedDB に保存 (syncStatus = 'pending')
     │
     ▼ (ネットワーク復帰時)
Background Sync API トリガー
     │
     ▼
Sync Engine (サーバー側)
     │
     ├── コンフリクトなし → マージ → syncStatus = 'synced'
     │
     └── コンフリクトあり → タイムスタンプ比較
              │
              ├── サーバー版が新しい → ユーザーに選択肢提示
              └── クライアント版が新しい → サーバー上書き
```

## 3. データベース設計

### 3.1 主要テーブル

#### t_construction_project（施工プロジェクト）
```sql
CREATE TABLE t_construction_project (
    project_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_code        VARCHAR(20) UNIQUE NOT NULL,
    project_name        VARCHAR(200) NOT NULL,
    site_address        VARCHAR(300),
    site_location       GEOMETRY(POINT, 4326),
    contract_amount     BIGINT,
    start_date          DATE,
    end_date            DATE,
    manager_id          UUID REFERENCES t_employee(emp_id),
    branch_id           UUID REFERENCES t_branch(branch_id),
    status              VARCHAR(20) DEFAULT 'active',
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_schedule（工程）
```sql
CREATE TABLE t_schedule (
    schedule_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_construction_project(project_id),
    task_name           VARCHAR(200) NOT NULL,
    parent_id           UUID REFERENCES t_schedule(schedule_id),
    planned_start       DATE,
    planned_end         DATE,
    actual_start        DATE,
    actual_end          DATE,
    progress_rate       DECIMAL(5,2) DEFAULT 0,
    is_critical         BOOLEAN DEFAULT FALSE,
    sort_order          INT,
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_daily_site_report（作業日報）
```sql
CREATE TABLE t_daily_site_report (
    report_id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_construction_project(project_id),
    report_date         DATE NOT NULL,
    weather             VARCHAR(20),
    temperature_max     DECIMAL(4,1),
    temperature_min     DECIMAL(4,1),
    work_content        JSONB,  -- [{task, workers, equipment, remarks}]
    safety_notes        TEXT,
    reporter_id         UUID REFERENCES t_employee(emp_id),
    approved_by         UUID,
    approved_at         TIMESTAMPTZ,
    sync_version        BIGINT DEFAULT 1,
    client_id           VARCHAR(50),  -- オフラインデバイス識別子
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(project_id, report_date, client_id)
);
```

#### t_site_photo（現場写真）
```sql
CREATE TABLE t_site_photo (
    photo_id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_construction_project(project_id),
    file_path           VARCHAR(500) NOT NULL,
    thumbnail_path      VARCHAR(500),
    captured_at         TIMESTAMPTZ,
    location            GEOMETRY(POINT, 4326),
    category            VARCHAR(30),  -- '出来形'/'材料'/'安全'/'全景'/'その他'
    work_type           VARCHAR(100),
    description         TEXT,
    ai_tags             JSONB,  -- AI自動分類タグ
    exif_data           JSONB,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_photo_project ON t_site_photo(project_id, captured_at);
```

#### t_electronic_board（電子黒板）
```sql
CREATE TABLE t_electronic_board (
    board_id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    photo_id            UUID REFERENCES t_site_photo(photo_id),
    project_name        VARCHAR(200),
    work_type           VARCHAR(100),
    measurement_point   VARCHAR(100),
    design_value        VARCHAR(50),
    actual_value        VARCHAR(50),
    contractor          VARCHAR(100),
    date                DATE,
    hash_value          VARCHAR(64),  -- 改ざん検知用SHA-256
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_worker_attendance（作業員入退場）
```sql
CREATE TABLE t_worker_attendance (
    attendance_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_construction_project(project_id),
    worker_id           UUID,
    worker_name         VARCHAR(100),
    company_name        VARCHAR(100),
    check_in_at         TIMESTAMPTZ,
    check_out_at        TIMESTAMPTZ,
    method              VARCHAR(20),  -- 'qr_code'/'nfc'/'manual'
    qualifications      JSONB,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_equipment（重機管理）
```sql
CREATE TABLE t_equipment (
    equipment_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    equipment_name      VARCHAR(100) NOT NULL,
    equipment_type      VARCHAR(50),
    project_id          UUID,
    gps_device_id       VARCHAR(50),
    current_location    GEOMETRY(POINT, 4326),
    status              VARCHAR(20) DEFAULT 'active',
    operating_hours     DECIMAL(10,1),
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

## 6. AI機能設計

### 6.1 AI写真分類
- モデル: Azure Custom Vision / TensorFlow.js（オフライン推論可）
- 分類カテゴリ: 出来形、材料、安全設備、全景、重機、作業員
- オフラインモデルサイズ: < 20MB

### 6.2 AI工程分析
- 過去工事データに基づく遅延リスク予測
- 天候予報データとの連携による作業可否予測
