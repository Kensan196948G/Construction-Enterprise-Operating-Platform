## 1. 部署概要

### 1.1 組織上の位置づけ
工事部は施工本部に属し、全社の施工現場を統括する。各現場の監理技術者・主任技術者を配置し、工程・原価・品質・安全の4大管理を遂行する。支店工事部との連携により全国の施工現場を管理する。

### 1.2 部署ミッション
- 全施工現場の工程通りの完成
- 原価管理による利益確保
- 品質基準の遵守と品質向上
- 労働災害ゼロの達成
- i-Construction 2.0対応のICT施工推進

### 1.3 主要メンバー構成
| 役職 | 人数（想定） | 主な業務 |
|------|-------------|---------|
| 工事部長 | 1名 | 全社施工統括 |
| 次長 | 2名 | 大型案件統括、支店指導 |
| 工事課長 | 3～5名 | 複数現場の統括管理 |
| 現場代理人 | 案件数分 | 現場常駐管理 |
| 監理技術者 | 案件数分 | 技術的総合管理 |
| 主任技術者 | 案件数分 | 施工技術管理 |

## 2. 現行業務フロー

### 2.1 工程管理業務
```
実行予算策定（着工前）
    ↓
施工計画書作成
    ↓
工程表作成（バーチャート/ネットワーク式）
    ↓
日々の施工（作業日報記録）
    ↓
週次工程会議（進捗確認・調整）
    ↓
月次出来高確認
    ↓
発注者への月次報告
    ↓
工程変更対応（天候・設計変更等）
```

**現行の課題**
- 工程表がExcelで作成されており、リアルタイム更新困難
- 現場からの進捗報告が電話・FAXで本社への伝達が遅い
- 複数現場の進捗を横断的に把握できない
- 天候による工程影響の予測ができない

### 2.2 日報管理業務
```
現場代理人/監理技術者が日報を手書きまたはExcel入力
    ↓
天候・気温・作業内容・人員配置・使用機械を記録
    ↓
安全関連（KY活動結果・巡視結果）の記録
    ↓
写真台帳との紐づけ
    ↓
月末に月報として整理
    ↓
発注者への提出
```

**現行の課題**
- 手書き日報の転記作業が非効率
- 圏外現場での電子入力ができない（最重要課題）
- 写真との紐づけが手動
- 日報データの全社集約・分析ができない

## 3. 業務要件（詳細）

### 3.1 工程管理

#### 3.1.1 工程表作成・管理
| 要件 | 詳細 |
|------|------|
| 工程表形式 | バーチャート＋ネットワーク式（CPM対応） |
| 階層管理 | 大工程→中工程→小工程→日工程の4階層 |
| クリティカルパス | 自動算出・赤線表示 |
| マイルストーン | 発注者検査日・材料搬入日等の管理 |
| 休工日管理 | 天候休工・祝日・自主休工の管理 |
| 変更履歴 | 当初工程・変更工程のバージョン管理 |

#### 3.1.2 天候連動工程管理
- 気象庁APIとの連携による天気予報表示
- 天候による作業可否の自動判定ルール設定
  - 例：風速15m/s以上→クレーン作業中止
  - 例：雨量10mm/h以上→コンクリート打設中止
  - 例：波高1.5m以上→海上作業中止
- 天候予測に基づく工程影響のAI分析

#### 3.1.3 工程進捗報告
- 各現場からの日次進捗入力（オフライン対応必須）
- 計画進捗率vs実績進捗率のイナズマ線表示
- 遅延アラート（計画比7日以上遅延で自動通知）
- 工事部長への週次サマリー自動生成

---

### 3.2 出来高管理

#### 3.2.1 出来高数量入力
| 項目 | 説明 |
|------|------|
| 工種・種別・細別 | 内訳書に基づく階層管理 |
| 計画数量 | 設計数量・契約数量 |
| 当月実施数量 | 当月の施工数量入力 |
| 累計実施数量 | 自動計算 |
| 進捗率 | 累計数量÷計画数量（自動計算） |
| 金額換算 | 単価×数量（自動計算） |

#### 3.2.2 出来形管理
- 出来形管理図の自動生成（規格値との比較）
- 設計値・規格値・実測値の一覧表
- i-Construction対応の3次元出来形管理
- ドローン測量データとの連携による面的出来形管理

#### 3.2.3 月次出来高集計
- 月末の出来高集計→発注者への出来高請求書生成
- 出来高推移グラフ（S字カーブ）
- 計画出来高vs実績出来高の対比表

---

### 3.3 原価管理

#### 3.3.1 実行予算管理
```
設計金額（受注金額）
    ↓
実行予算策定（工事部＋管理本部）
    ├── 労務費予算
    ├── 材料費予算
    ├── 外注費予算
    └── 経費予算
    ↓
月次原価管理（実績vs予算）
    ↓
最終原価予測（EAC）更新
    ↓
利益率予測更新
```

#### 3.3.2 日次原価入力
| 原価区分 | 入力項目 | 入力頻度 |
|---------|---------|---------|
| 労務費 | 作業員数×単価、社員労務費 | 日次 |
| 材料費 | 材料名・数量・単価、納品伝票 | 都度 |
| 外注費 | 協力会社名・作業内容・金額 | 月次 |
| 経費 | 仮設費・動力費・運搬費等 | 月次 |

#### 3.3.3 EAC（完成時総原価予測）
- 現在の原価進捗率に基づく完成時原価予測
- 3種類のEAC算出方式：
  1. CPI方式（原価実績率による予測）
  2. CPI×SPI方式（原価×工程の複合予測）
  3. 残作業見積方式（積上方式）
- EAC推移グラフ（月次更新）

### 3.4 現場写真管理

#### 3.4.1 撮影・管理要件
| 要件 | 詳細 |
|------|------|
| 撮影形式 | JPEG（5MB以下推奨）、オリジナルサイズも保存 |
| 位置情報 | GPS座標自動取得（EXIF） |
| 日時情報 | 撮影日時自動取得（EXIF） |
| 分類タグ | 工種・測点・撮影目的で自動/手動タグ付け |
| AI自動分類 | 撮影内容のAI画像認識による自動分類 |
| 台帳生成 | 工事写真台帳の自動生成（国交省デジタル写真管理基準準拠） |

#### 3.4.2 国交省デジタル写真管理基準対応
- 写真区分（着手前/施工中/出来形/品質/完成）の管理
- 写真情報のXML管理（PHOTO.XML準拠）
- 改ざん検知（ハッシュ値の管理）
- 電子納品形式でのエクスポート

---

### 3.5 電子黒板

#### 3.5.1 業務要件
- 工事写真に工事情報をオーバーレイ表示する電子黒板機能
- 記載項目：工事名・工種・測定箇所・設計値・実測値・施工者名・日付
- テンプレート管理（工種別の黒板レイアウト）
- 改ざん防止：撮影時点のデータをSHA-256でハッシュ化
- 国交省の電子黒板使用ガイドライン準拠

---

### 3.6 KY（危険予知）活動管理

#### 3.6.1 日常KY活動
| 記録項目 | 説明 |
|---------|------|
| 作業日 | 実施日 |
| 作業内容 | 当日の主要作業 |
| 参加者 | 参加者全員の氏名 |
| 危険要因 | 予想される危険を列挙 |
| リスクランク | 危険度の評価（A/B/C） |
| 対策 | 各危険要因に対する対策 |
| 行動目標 | 全員で確認する安全行動目標 |
| リーダー確認 | 班長/職長の確認サイン |

#### 3.6.2 オフライン対応（最重要）
- 圏外環境でのKY活動記録入力
- タブレットでのタッチ入力最適化
- 参加者をQRコード/NFC読取で自動入力
- ネットワーク復帰時に自動同期

### 3.7 作業員入退場管理

#### 3.7.1 入退場記録方式
| 方式 | 対象 | 精度 |
|------|------|------|
| QRコード | 作業員証のQRコード読取 | ○ |
| NFC | ICカード読取 | ○ |
| 顔認証 | カメラによる顔認証（将来対応） | △ |
| 手動入力 | 上記が使えない場合 | △ |

#### 3.7.2 管理要件
- リアルタイム在場者一覧表示
- 建設キャリアアップシステム（CCUS）との連携
- 有資格者配置の自動確認（資格情報とのマッチング）
- 入退場ログの保存（労災時の在場証明）
- 協力会社別の施工体制台帳との整合確認

## 4. オフライン対応要件（最重要）

### 4.1 オフライン必須機能
以下の機能はネットワーク接続なしで完全に動作すること：

| 機能 | オフライン対応 | 理由 |
|------|:------------:|------|
| 日報入力 | 必須 | 圏外現場での日次業務 |
| 写真撮影・保存 | 必須 | 施工記録の日常業務 |
| KY活動記録 | 必須 | 毎朝の安全活動 |
| 出来高入力 | 必須 | 計測データの即時記録 |
| 工程進捗入力 | 必須 | 日次の進捗確認 |
| 原価入力 | 必要 | 材料・労務の日次記録 |
| 入退場記録 | 必要 | QRコードオフライン読取 |
| 重機管理 | 望ましい | 始業前点検記録 |

### 4.2 オフライン同期ルール
- ネットワーク復帰を自動検知して同期開始
- 同期中はプログレスバーで進捗表示
- コンフリクト発生時はユーザーに選択肢提示
- 写真はバックグラウンドでアップロード（WiFi優先）
- 同期失敗時はリトライ（最大5回、指数バックオフ）
