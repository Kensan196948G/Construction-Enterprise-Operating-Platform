## 🛠 Development

### 系統 D: data-web Rollup external 化

Loop #10 で `cesium.d.ts` を追加し TS 型解決を通したが、Vite/Rollup は実バンドル時に `cesium` を解決しようとしていた。これは TS 型システムと Rollup の bundler 解析が別レイヤーである典型例。

```typescript
// 11_統合データ基盤/.../frontend/vite.config.ts
export default defineConfig({
  // ...
  build: {
    rollupOptions: {
      external: ["cesium", /^cesium\//],  // ← Loop #11 追加
    },
  },
});
```

`external` を指定することで Rollup に「`cesium` は外部から動的供給される optional 依存」と宣言。バンドル対象から外れ、解決失敗エラーが消える。`DigitalTwinScene.tsx` 側の `try { await import("cesium") } catch {}` の graceful fallback は機能維持。
