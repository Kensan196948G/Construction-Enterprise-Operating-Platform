## 2. データレイク層設計

### 2.1 ゾーン構成
| ゾーン | 用途 | 技術 |
|--------|------|------|
| Raw Zone | 生データ保存 | MinIO (S3互換) |
| Curated Zone | クレンジング・変換済み | PostgreSQL + dbt |
| Serving Zone | 分析・可視化用 | PostgreSQL + Materialized Views |

### 2.2 データカタログスキーマ
```sql
CREATE TABLE t_data_catalog (
    catalog_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dataset_name        VARCHAR(200) NOT NULL,
    source_system       VARCHAR(50),  -- 部門システム名
    description         TEXT,
    schema_definition   JSONB,
    data_owner          VARCHAR(100),
    update_frequency    VARCHAR(20),  -- 'realtime'/'daily'/'weekly'
    row_count           BIGINT,
    last_updated        TIMESTAMPTZ,
    data_quality_score  DECIMAL(5,2),
    tags                TEXT[],
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.2 dbt変換モデル例
```sql
-- models/curated/fct_project_summary.sql
WITH projects AS (
    SELECT * FROM {{ ref('stg_projects') }}
),
costs AS (
    SELECT project_id,
           SUM(actual_amount) as total_cost
    FROM {{ ref('stg_cost_records') }}
    GROUP BY project_id
),
safety AS (
    SELECT project_id,
           COUNT(*) FILTER (WHERE record_type = 'accident') as accidents,
           COUNT(*) FILTER (WHERE record_type = 'near_miss') as near_misses
    FROM {{ ref('stg_safety_records') }}
    GROUP BY project_id
)
SELECT
    p.*,
    c.total_cost,
    (p.contract_amount - c.total_cost)::numeric / p.contract_amount as profit_rate,
    s.accidents,
    s.near_misses
FROM projects p
LEFT JOIN costs c ON p.project_id = c.project_id
LEFT JOIN safety s ON p.project_id = s.project_id
```

## 5. デジタルツイン設計

### 5.1 データフロー
```
現場センサー → MQTT → Kafka → 
  ├── TimescaleDB（時系列保存）
  └── CesiumJS/Unity（リアルタイム3D表示）
       ├── BIM/CIMモデル
       ├── IoTセンサーデータオーバーレイ
       ├── GPS/AIS位置データ
       └── AI解析結果オーバーレイ
```

### 5.2 技術選定
- 3D可視化: CesiumJS（Web） / Unity WebGL（高精細）
- 空間データ: 3D Tiles + PostGIS
- リアルタイム: WebSocket + MQTT
