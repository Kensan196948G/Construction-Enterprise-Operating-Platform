## 2. データベース設計

### t_purchase_order（発注）
```sql
CREATE TABLE t_purchase_order (
    po_id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    po_number           VARCHAR(20) UNIQUE NOT NULL,
    project_id          UUID,
    supplier_id         UUID REFERENCES t_supplier(supplier_id),
    items               JSONB,  -- [{material, qty, unit, unit_price, amount}]
    total_amount        BIGINT,
    status              VARCHAR(20) DEFAULT 'draft',
    requested_by        UUID,
    approved_by         UUID,
    delivery_date       DATE,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### t_supplier（協力会社）
```sql
CREATE TABLE t_supplier (
    supplier_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_code       VARCHAR(10) UNIQUE,
    company_name        VARCHAR(200) NOT NULL,
    category            VARCHAR(50),  -- '資材'/'外注'/'リース'/'運搬'
    evaluation_score    DECIMAL(5,2),
    contact_info        JSONB,
    contract_info       JSONB,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### t_inventory（在庫）
```sql
CREATE TABLE t_inventory (
    inventory_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    material_id         UUID REFERENCES t_material(material_id),
    location_type       VARCHAR(20),  -- 'site'/'warehouse'
    location_id         UUID,
    quantity            DECIMAL(15,4),
    unit                VARCHAR(20),
    min_quantity        DECIMAL(15,4),
    last_updated        TIMESTAMPTZ DEFAULT NOW()
);
```

### t_material_price（資材単価履歴）
```sql
CREATE TABLE t_material_price (
    price_id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    material_id         UUID,
    supplier_id         UUID,
    unit_price          DECIMAL(15,2),
    effective_date      DATE,
    source              VARCHAR(30),  -- 'quotation'/'contract'/'market'
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

## 4. AI価格予測設計
- モデル: Prophet（時系列予測）
- 入力: 過去資材単価、建設物価指数、原油価格、為替レート
- 出力: 3ヶ月先の予測単価 + 信頼区間
- 更新: 月次バッチ
