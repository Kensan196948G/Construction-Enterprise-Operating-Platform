## 1. 概要
### 1.1 目的
資材発注・在庫管理・リース管理・協力会社管理を一元化し、AI価格予測によるコスト最適化を実現する。

---

## 2. 機能要件

### 2.1 資材発注
- FR-PMP-001: 発注依頼→承認→発注のワークフロー
- FR-PMP-002: 発注書自動生成
- FR-PMP-003: 発注履歴管理
- FR-PMP-004: 複数見積比較

### 2.2 在庫管理
- FR-PMP-010: 資材在庫管理（現場別・倉庫別）
- FR-PMP-011: 在庫アラート（最低在庫量）
- FR-PMP-012: バーコード/QRコード管理

### 2.3 リース管理
- FR-PMP-020: 重機・機材リース管理
- FR-PMP-021: リース期間・返却管理
- FR-PMP-022: コスト管理

### 2.4 協力会社管理
- FR-PMP-030: 協力会社マスタ管理
- FR-PMP-031: 評価管理（品質・納期・安全）
- FR-PMP-032: 契約管理

### 2.5 単価比較・AI価格予測
- FR-PMP-040: 資材単価比較DB
- FR-PMP-041: 市場価格トレンド表示
- FR-PMP-042: AI価格予測（原材料価格変動予測）
- FR-PMP-043: 納期管理・遅延アラート

---

## 3. 非機能要件
- NFR-PMP-001: Entra ID SSO
- NFR-PMP-002: モバイル対応（現場からの発注依頼）

---

## 4. 技術スタック

| レイヤー | 技術 |
|----------|------|
| フロントエンド | React + TypeScript |
| バックエンド | Python FastAPI |
| データベース | PostgreSQL |
| AI | Azure OpenAI / Prophet（価格予測） |
| 認証 | Entra ID + HENNGE SSO |

---

## 5. 統合要件
- 施工管理からの資材発注依頼受信
- 管理本部（経理）への支払データ連携
- 経営ダッシュボードへの資材コストデータ提供
