## 1. 部署概要

### 1.1 組織上の位置づけ
購買部は資材調達・外注管理・リース管理・協力会社管理を統括する。施工本部の各現場が必要とする資材・機材・外注を適正な品質・価格・納期で調達することが主要業務。

### 1.2 部署ミッション
- 資材・機材の適正調達（QCD最適化）
- 協力会社の育成・評価・管理
- 調達コストの削減と原価低減への貢献
- サプライチェーンリスクの管理
- パートナーシップ構築宣言に基づく適正取引の推進

## 2. 業務要件（詳細）

### 2.1 資材発注管理

#### 2.1.1 発注業務フロー
```
現場からの資材発注依頼（施工管理システム連携）
    ↓
購買部での依頼内容確認
    ↓
在庫確認（他現場からの転用可否含む）
    ↓
複数業者への見積依頼
    ↓
見積比較表の作成
    ↓
発注先決定（金額・納期・品質を総合判断）
    ↓
発注書発行
    ↓
納入確認・検収
    ↓
支払依頼（経理部連携）
```

#### 2.1.2 発注管理要件
| 項目 | 説明 |
|------|------|
| 発注依頼管理 | 現場からの依頼の受付・ステータス管理 |
| 見積比較 | 複数業者の見積を並列比較する機能 |
| 発注承認 | 金額に応じた承認ワークフロー |
| 発注書発行 | 自動生成（PDF）・電子送信 |
| 納期管理 | 発注品の納期追跡・遅延アラート |
| 検収管理 | 納品時の検収記録 |
| 返品管理 | 不良品の返品・交換記録 |

#### 2.1.3 発注承認基準
| 金額 | 承認者 |
|------|--------|
| 50万円未満 | 購買課長 |
| 50万～300万円 | 購買部長 |
| 300万～1,000万円 | 管理本部長 |
| 1,000万円以上 | 取締役 |

### 2.2 在庫管理

#### 2.2.1 管理要件
| 項目 | 説明 |
|------|------|
| 在庫場所 | 各現場仮設倉庫・本社倉庫・支店倉庫 |
| 入出庫管理 | 入庫（納品時）・出庫（使用時）の記録 |
| 棚卸 | 月次の在庫確認 |
| 最低在庫量 | 資材ごとの最低在庫量設定とアラート |
| 転用管理 | 工事完了現場から別現場への資材転用 |
| バーコード/QR | 資材のバーコード・QRコード管理 |

#### 2.2.2 在庫最適化要件
- 過去の使用実績に基づく適正在庫量の算出
- 在庫回転率の分析
- デッドストックの検知とアラート
- 現場間の在庫共有による調達コスト削減

### 2.3 リース管理

#### 2.3.1 管理対象
| 対象 | 例 |
|------|-----|
| 重機 | バックホウ、クレーン車、ブルドーザー |

#### 2.3.2 管理要件

|------|------|
| リース契約管理 | 契約番号・契約先・期間・金額 |
| 配置管理 | どの現場にどの機材を配置しているか |
| 返却管理 | リース期限・返却予定の管理 |
| コスト管理 | 日額・月額の管理、延長時の追加コスト |
| 稼働管理 | リース機材の稼働率管理 |
| 比較分析 | リースvs購入の経済性比較ツール |

### 2.4 協力会社管理

#### 2.4.1 管理要件
| 項目 | 説明 |
|------|------|
| 協力会社マスタ | 会社名・代表者・資本金・従業員数・保有資格 |
| 建設業許可 | 許可番号・許可業種・有効期限 |
| 保険加入状況 | 社会保険・労災保険の加入確認 |
| 施工実績 | 過去の施工実績・施工能力 |
| 評価管理 | 品質・工程・安全・コストの4軸評価 |
| 安全管理体制 | 安全書類の提出状況 |
| 取引履歴 | 過去の受注金額・件数 |

#### 2.4.2 協力会社評価制度
| 評価項目 | 配点 | 評価基準 |
|---------|------|---------|
| 品質 | 25点 | 不適合件数、手直し頻度 |
| 工程 | 25点 | 工期遵守率、対応の迅速さ |
| 安全 | 25点 | 事故発生率、安全書類提出率 |
| コスト | 25点 | 単価水準、コスト削減提案 |

- 年次評価の実施
- 評価ランク：S/A/B/C/D
- Dランクの協力会社は改善計画の提出を要求
- 評価結果に基づく発注配分の調整

#### 2.4.3 パートナーシップ構築宣言対応
- 下請法・建設業法に基づく適正取引の管理
- 支払条件の適正化（手形サイト短縮等）の管理
- 協力会社との対話記録の管理

### 2.5 単価管理・AI価格予測

#### 2.5.1 単価管理要件
| 項目 | 説明 |
|------|------|
| 資材単価DB | 品目ごとの最新単価・過去単価の履歴管理 |
| 業者別単価 | 同一品目の業者別単価比較 |
| 市場価格連動 | 建設物価・積算資料との連動 |
| 単価契約管理 | 協定単価・フレーム単価の管理 |

#### 2.5.2 AI価格予測要件
| 予測対象 | 入力データ | 予測期間 |
|---------|-----------|---------|
| 鉄鋼材 | 過去単価、鉄鉱石価格、為替 | 3ヶ月先 |
| セメント | 過去単価、原油価格、電力価格 | 3ヶ月先 |
| 生コンクリート | 過去単価、セメント価格、骨材価格 | 3ヶ月先 |
| 燃料 | 原油価格、為替 | 1ヶ月先 |
| 鋼矢板 | 過去単価、鉄鋼市況 | 3ヶ月先 |

- 予測結果の信頼区間表示
- 予測精度の月次検証（MAPE 10%以内を目標）
- 価格上昇が見込まれる場合の早期調達提案

### 2.6 納期管理

#### 2.6.1 管理要件
| 項目 | 説明 |
|------|------|
