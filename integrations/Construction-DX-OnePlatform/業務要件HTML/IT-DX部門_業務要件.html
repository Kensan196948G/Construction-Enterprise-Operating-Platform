1. 部署概要

1.1 組織上の位置づけ

IT/DX部門は全社のIT基盤の構築・運用・セキュリティ管理を担う。Construction DX One Platformの構築推進役であり、全部門システムの統合認証・監視・運用を統括する最重要部門。

1.2 部署ミッション

  • 全社IT基盤の安定運用（稼働率99.5%以上）
  • ゼロトラストセキュリティの実現
  • Construction DX One Platformの構築推進
  • 全社DX推進・社内IT支援
  • 情報セキュリティインシデントの防止と対応

1.3 現行IT環境

システム 用途 備考
Microsoft 365 メール・Office・Teams 全社利用
Entra ID ID管理・認証 全社認証基盤
HENNGE SSO・セキュリティ M365アクセス制御
SharePoint Online 文書管理・ポータル 全社利用
Exchange Online メール M365に含む
FortiGate ファイアウォール・VPN 拠点間・リモートVPN
Cisco ネットワーク機器 スイッチ・ルーター
DeskNet's NEO グループウェア スケジュール・ワークフロー

2. 業務要件（詳細）

2.1 ITSM（ITサービス管理）

2.1.1 インシデント管理

フェーズ 業務内容
検知 ユーザー申告/監視アラート/AI HelpDesk
記録 チケット起票（自動分類＋優先度設定）
分類 カテゴリ分類（ネットワーク/端末/M365/業務AP/セキュリティ）
優先度判定 影響度×緊急度マトリクス
調査・診断 ナレッジベース検索・ログ分析
解決 対処実施・ユーザー確認
クローズ 解決確認・フィードバック

2.1.2 優先度マトリクス

緊急度：高 緊急度：中 緊急度：低
影響度：高 P1（重大） P2（高） P3（中）
影響度：中 P2（高） P3（中） P4（低）
影響度：低 P3（中） P4（低） P5（計画）

2.1.3 SLA目標

優先度 初動対応 解決目標
P1（重大） 15分以内 4時間以内
P2（高） 30分以内 8時間以内
P3（中） 2時間以内 24時間以内
P4（低） 4時間以内 72時間以内
P5（計画） 1営業日以内 計画に従う

2.1.4 問題管理

  • 繰り返し発生するインシデントの根本原因分析
  • 既知の問題（Known Error）のDB管理
  • ワークアラウンド（暫定対処法）の管理
  • 恒久対策の計画・実施・検証

2.1.5 変更管理

変更種別 承認要件 例
標準変更 事前承認済み パッチ適用、ユーザー追加
通常変更 CAB（変更諮問委員会）承認 サーバー増設、ネットワーク変更
緊急変更 緊急CAB承認 セキュリティ脆弱性対応

2.2 CMDB（構成管理データベース）

2.2.1 管理対象

CI種別 想定件数 管理項目
サーバー 20～50台 OS・スペック・IP・ロール
PC 200～500台 OS・ユーザー・Entra ID
ネットワーク機器 50～100台 機種・IP・ポート構成
プリンター 30～50台 機種・場所・ネットワーク
ソフトウェア 100～200件 ライセンス数・割当状況
クラウドサービス 20～30件 M365・Azure・SaaS

2.2.2 自動ディスカバリ

  • ネットワークスキャンによるデバイス自動検出
  • Entra IDからのデバイス情報同期
  • SNMP v3によるネットワーク機器の自動登録
  • ソフトウェアインベントリの自動収集

2.2.3 ライセンス管理

  • Microsoft 365ライセンスの割当・利用状況
  • ソフトウェアライセンスのコンプライアンス管理
  • ライセンス過不足のアラート
  • ライセンスコストの最適化分析

2.3 セキュリティ監視（SIEM/SOC）

2.3.1 ログ収集対象

ソース ログ種別 収集方式
FortiGate ファイアウォールログ・VPNログ・IPS Syslog (UDP/514)
Cisco スイッチログ・ルーターログ Syslog/SNMP
Entra ID サインインログ・監査ログ Microsoft Graph API
Exchange Online メールフローログ Microsoft Graph API
Windows Server イベントログ Wazuh Agent
各業務システム アプリケーションログ Fluentd/API

2.3.2 検知ルール（主要なもの）

ルール名 条件 重要度
ブルートフォース攻撃 同一IPから5分間に10回以上のログイン失敗 高
不審なVPN接続 通常と異なる地域からのVPN接続 高
マルウェア検知 FortiGate IPSでのマルウェア検知 最高
特権アカウント使用 管理者アカウントの通常外使用 高
大量データ送信 通常の10倍以上のデータ送信 中
営業時間外アクセス 深夜・休日のシステムアクセス 低
退職予定者アクセス 退職予定者の大量ファイルアクセス 中

2.3.3 インシデント対応フロー

セキュリティアラート発生
    ↓（自動）
チケット自動起票（P1扱い）
    ↓（15分以内）
IT/DX部門担当者が初動対応
    ↓
影響範囲の特定
    ↓
封じ込め（端末隔離・アカウント停止等）
    ↓
根本原因の調査
    ↓
復旧措置
    ↓
再発防止策の策定
    ↓（重大インシデントの場合）
経営層への報告

2.5 AI HelpDesk

2.5.1 業務要件

要件 詳細
自動応答 よくある問い合わせへのAI自動回答
ナレッジ検索 過去のチケット解決履歴からの回答検索
チケット起票 AI対話からのチケット自動起票
エスカレーション AIで解決できない場合の担当者エスカレーション
対応言語 日本語（主）、英語（補助）

2.5.2 FAQ例

カテゴリ 質問例

パスワード 「パスワードを忘れた」「パスワードを変更したい」
プリンター 「印刷できない」「プリンターが認識されない」
