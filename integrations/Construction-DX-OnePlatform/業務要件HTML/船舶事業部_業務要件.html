対象部署 船舶事業部
対象システム Marine Fleet Management

1. 部署概要

1.1 組織上の位置づけ

船舶事業部は、自社保有船舶（起重機船・浚渫船・台船・曳船等）の運航管理・保守管理を担う。港湾・海上工事を主力とするみらい建設工業にとって、船舶は最重要の施工設備であり、その稼働率最大化と安全運航が事業基盤を支える。

1.2 部署ミッション

  • 全船舶の安全運航の確保
  • 船舶稼働率の最大化
  • 保守点検の計画的実施による突発故障の防止
  • 燃費最適化によるコスト削減とCO2排出量削減
  • 浚渫工事の施工管理支援

2. 業務要件（詳細）

2.1 船舶稼働管理

2.1.1 保有船舶種別（想定）

船種 用途 管理項目
起重機船 重量物の吊込み・据付 吊上能力・ブーム長
浚渫船 港湾・河川の浚渫 浚渫能力（m³/h）
台船 資材運搬・作業足場 積載能力・甲板面積
曳船 台船・起重機船の曳航 馬力・曳航能力
作業船 各種海上作業 作業内容に依存
揚錨船 アンカーの打設・揚収 ウインチ能力
交通船 作業員の現場往来 定員・速力

2.1.2 稼働スケジュール管理

要件 詳細
配船計画 工事別の船舶配置計画（ガントチャート）
稼働/非稼働管理 稼働中/待機中/修繕中/ドック入り のステータス管理
稼働率分析 船種別・月別の稼働率集計
回航計画 現場間の回航スケジュール管理
共用管理 複数現場での船舶の共用スケジュール調整

2.1.3 配船計画の制約条件

  • 気象条件（風速・波高・潮流）による作業可否
  • 船舶のドック入り予定との調整
  • 乗組員の配置（有資格者の充足確認）
  • 回航日数の考慮

2.2 AIS・GPS連携

2.2.1 リアルタイム位置管理

要件 詳細
AIS受信 船舶自動識別装置からのデータ受信
GPS追跡 全船舶のGPSリアルタイム位置表示
GIS地図表示 海図上への船舶位置プロット
航跡表示 過去の航行履歴の軌跡表示
ジオフェンス 指定区域からの逸脱アラート

2.2.2 受信データ

データ 更新頻度 ソース
位置（緯度経度） 10秒～3分 AIS/GPS
速力（ノット） 10秒～3分 AIS/GPS
針路（度） 10秒～3分 AIS/GPS
船舶識別 固定 MMSI
船舶状態 変更時 AIS Class A

2.3 燃料管理

2.3.1 管理要件

項目 説明
給油記録 給油日・給油量・油種・単価・給油場所
消費量記録 日次の燃料消費量
燃費分析 船種別・工事別の燃費（L/h、L/kWh）
コスト分析 燃料コストの月次集計・予算比較
在油管理 各船舶の燃料残量管理
CO2算出 燃料消費量からのCO2排出量自動計算

2.3.2 省エネ分析

  • 運航パターンと燃料消費の相関分析
  • 最適運航速度の提案（燃費最適化）
  • 船齢・機関状態と燃費の関係分析
  • ESG/SDGs報告用のCO2排出データ集計

2.4 保守点検管理

2.4.1 点検種別

点検種別 頻度 実施者
日常点検 毎日 乗組員
定期点検 月次 機関士
中間検査 2.5年ごと 船級協会
定期検査 5年ごと 船級協会
ドック入り 2.5年ごと 造船所

2.4.2 管理要件

項目 説明
点検スケジュール 年間点検計画の作成・管理
点検記録 点検チェックリスト・結果の記録
故障記録 故障内容・原因・対応・停止期間
修理履歴 修理内容・費用・修理業者
部品管理 主要部品の在庫・交換履歴
予防保全 稼働時間ベースの予防保全アラート

2.4.3 予防保全要件

  • 機関の稼働時間に基づく部品交換時期の自動算出
  • 過去の故障パターンに基づく故障予測（将来：AI対応）
  • ドック入り時の修繕項目の事前計画

2.5 航行記録管理

2.5.1 航行日誌（ログブック）電子化

記録項目 説明
日時 記録時刻
位置 緯度・経度
天候 天気・風向・風速・波高
作業内容 航行/作業/停泊の区分と内容
乗組員 当日の乗船者名簿
特記事項 事故・故障・異常等

2.5.2 気象データ連携

  • 気象庁データとの連携（天気予報・波浪予報）
  • 海上気象の自動記録
  • 荒天時の作業中止判断支援（風速・波高による基準）

2.6 浚渫管理

2.6.1 業務要件

項目 説明
浚渫量管理 日次の浚渫量（m³）の記録
土砂運搬記録 運搬先・運搬量・運搬回数
深浅測量管理 施工前後の深浅測量データ管理
土質記録 浚渫土の土質・含水比等の記録
出来高管理 浚渫出来高と設計量の対比
GIS表示 浚渫区域のGIS上での可視化

2.6.2 深浅測量データ管理

  • マルチビーム測深機のデータ取込
  • 施工前後の海底地形3D表示
  • 計画深度との差分表示
  • 出来形管理図の自動生成

3. 安全管理要件（海上特有）

3.1 海上作業安全基準

基準 条件
作業中止（風速） 10m/s以上で軽作業中止、15m/s以上で全作業中止
作業中止（波高） 0.5m以上で潜水作業中止、1.5m以上で海上作業中止
作業中止（視程） 500m未満で船舶航行注意、100m未満で航行中止
落水対策 ライフジャケット常時着用、救命設備の配置
荒天準備 台風接近時の係留強化・避難計画

3.2 乗組員資格管理

資格 対象
海技士（航海/機関） 船長・機関長
小型船舶操縦免許 交通船操縦者
潜水士 潜水作業者
玉掛け 起重機船作業者
クレーン運転 起重機船オペレーター
