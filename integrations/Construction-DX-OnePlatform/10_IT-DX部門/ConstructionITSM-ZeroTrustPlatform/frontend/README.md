# cdx-itsm-frontend

Construction DX ITSM & ZeroTrust Platform - Frontend (Vite + React 18).

## Quick start

```bash
npm install
npm run dev    # http://localhost:5173 (proxies /api -> :8000)
```

## ページ

| Path | 内容 |
|------|------|
| /tickets | チケット一覧 + Kanban |
| /cmdb | CMDB CI 一覧 + Cytoscape トポロジー |
| /siem | FortiGate/Wazuh メトリクス + Grafana リンク |
| /network | Cisco SNMP 監視 |
| /entra | Entra ID サインインログ + リスク |
| /ai | RAG AI HelpDesk チャット |
| /knowledge | ナレッジ記事 CRUD |
| /sla | SLA レポート |
