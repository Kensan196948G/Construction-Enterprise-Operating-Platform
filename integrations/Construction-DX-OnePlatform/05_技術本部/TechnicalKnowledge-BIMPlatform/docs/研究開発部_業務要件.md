## 1. 部署概要

### 1.1 組織上の位置づけ
研究開発部は技術本部に属し、新工法・新技術の研究開発、特許管理、学会活動を担う。将来の競争力の源泉となる技術シーズの創出と知的財産の保護が主要業務。

### 1.2 部署ミッション
- 新工法・新技術・新材料の研究開発
- 特許・実用新案の出願・管理
- 学会発表・論文投稿による技術的プレゼンス向上
- 国交省PRISM等の技術実証事業への参画
- 大学・研究機関との共同研究管理

## 2. 業務要件（詳細）

### 2.1 研究プロジェクト管理

#### 2.1.1 管理要件
| 項目 | 説明 |
|------|------|
| プロジェクト名 | 研究テーマ名 |
| 研究分類 | 基礎研究/応用研究/開発研究 |

- 研究費の適正執行管理

---

### 2.2 特許管理

#### 2.2.1 管理ライフサイクル
```
発明届出（社内発明者から）
    ↓
技術評価（出願価値の判断）
    ↓
出願準備（弁理士との調整）
    ↓
特許出願（国内/PCT）
    ↓
審査請求
    ↓
中間処理（拒絶理由通知への対応）
    ↓
特許査定/拒絶査定
    ↓
特許維持（年金支払い）
    ↓
権利活用（ライセンス・自社実施）
```

#### 2.2.2 管理項目
| 項目 | 説明 |
|------|------|
| 出願番号 | 特願XXXX-XXXXXX |
| 特許番号 | 特許第XXXXXXX号 |
| 発明者 | 社内発明者名 |
| 技術分野 | IPC分類 |
| 出願日 | 出願日 |
| 登録日 | 登録日 |
| 年金支払期限 | 次回年金納付期限 |
| 状態 | 出願中/登録/放棄/満了 |
| 関連研究 | 紐づく研究プロジェクト |

#### 2.2.3 アラート要件
- 年金納付期限の3ヶ月前・1ヶ月前・2週間前に自動通知
- 審査請求期限（出願から3年）のリマインダー
- 存続期間満了（出願から20年）のリマインダー
