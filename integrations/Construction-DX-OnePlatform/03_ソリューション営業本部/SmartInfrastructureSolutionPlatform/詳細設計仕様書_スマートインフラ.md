## 2. データベース設計

### 2.1 主要テーブル

#### t_solution_proposal（ソリューション提案）
```sql
CREATE TABLE t_solution_proposal (
    proposal_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    client_name         VARCHAR(200),
    solution_type       VARCHAR(50),  -- 'BIM_CIM'/'IoT'/'AI'/'Drone'/'DX'
    title               VARCHAR(200) NOT NULL,
    description         TEXT,
    estimated_cost      BIGINT,
    roi_estimate        DECIMAL(5,2),
    status              VARCHAR(20) DEFAULT 'draft',
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_bim_model（BIM/CIMモデル）
```sql
CREATE TABLE t_bim_model (
    model_id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    model_name          VARCHAR(200) NOT NULL,
    model_type          VARCHAR(30),  -- 'IFC'/'LandXML'/'CityGML'
    file_path           VARCHAR(500),
    file_size_mb        INT,
    project_id          UUID,
    metadata            JSONB,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_iot_device（IoTデバイス）
```sql
CREATE TABLE t_iot_device (
    device_id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    device_name         VARCHAR(100),
    device_type         VARCHAR(50),  -- 'sensor'/'camera'/'gateway'
    location            GEOMETRY(POINT, 4326),
    project_id          UUID,
    status              VARCHAR(20) DEFAULT 'active',
    last_data_at        TIMESTAMPTZ
);
```

#### t_drone_survey（ドローン測量）
```sql
CREATE TABLE t_drone_survey (
    survey_id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    survey_date         DATE NOT NULL,
    area                GEOMETRY(POLYGON, 4326),
    point_cloud_path    VARCHAR(500),
    ortho_image_path    VARCHAR(500),
    dem_path            VARCHAR(500),
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```
