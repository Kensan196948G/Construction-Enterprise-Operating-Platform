## 1. 部署概要

### 1.1 組織上の位置づけ
品質環境部は安全品質環境本部に属し、ISO9001（品質マネジメント）およびISO14001（環境マネジメント）の運用・維持、品質記録管理、環境管理を担う。

### 1.2 部署ミッション
- ISO9001品質マネジメントシステムの運用・維持・改善
- ISO14001環境マネジメントシステムの運用・維持・改善
- 施工品質の管理基準の策定・監視
- 環境負荷の低減（CO2排出量削減・産廃管理）
- SBTi目標に基づくカーボンニュートラル推進

### 2.2 不適合管理（NCR: Non-Conformance Report）

#### 2.2.1 管理フロー
```
不適合の発見（現場・検査・パトロール）
    ↓
不適合報告書（NCR）の作成
    ↓
原因分析（なぜなぜ分析）
    ↓
処置の決定（修正/手直し/特採/廃棄）
    ↓
処置の実施
    ↓
処置結果の検証
    ↓
是正処置（再発防止策）の策定
    ↓
是正処置の実施・有効性確認
    ↓
完了登録
```

#### 2.2.2 管理項目
| 項目 | 説明 |
|------|------|
| NCR番号 | 自動採番（年度-連番） |
| 発見者 | 発見した者の氏名・所属 |
| 不適合内容 | 不適合の詳細記述 |
| 影響範囲 | 品質・安全・環境への影響評価 |
| 原因分析 | なぜなぜ分析の記録 |
| 処置方法 | 修正/手直し/特採/廃棄 |
| 是正処置 | 再発防止策 |
| 期限 | 是正完了期限 |
| 完了確認者 | 品質環境部の確認者 |

### 2.3 ISO監査管理

#### 2.3.1 監査スケジュール管理
| 監査種別 | 頻度 | 実施者 |
|---------|------|--------|
| 内部監査 | 年1回 | 社内内部監査員 |
| サーベイランス審査 | 年1回 | 認証機関 |
| 更新審査 | 3年に1回 | 認証機関 |
| 特別監査 | 必要時 | 品質環境部 |

#### 2.3.2 内部監査管理要件
- 年間監査計画の作成・管理
- 監査チェックリストのテンプレート管理
- 監査所見の記録（不適合/観察事項/改善の機会）
- 是正処置要求書（CAR）の発行・追跡
- 監査証拠の管理（文書・記録・インタビュー記録）
- 内部監査員の資格管理・力量評価

#### 2.3.3 マネジメントレビュー支援
- マネジメントレビューのインプット資料自動集計
  - 監査結果、顧客満足度、プロセスパフォーマンス
  - 不適合・是正処置の状況
  - 前回からの変更事項
  - 改善の機会
- レビュー結果（アウトプット）の記録・追跡

### 2.4 環境管理

#### 2.4.1 CO2排出量管理

| Scope | 対象 | データソース |
|-------|------|------------|
| Scope 1 | 自社重機・車両の燃料消費 | 燃料使用量記録 |
| Scope 2 | 購入電力 | 電力使用量 |
| Scope 3 | 協力会社・資材運搬・廃棄物処理等 | 取引先データ |

##### 算定要件
- 環境省「温室効果ガス排出量算定・報告マニュアル」準拠
- 排出係数の管理（年度別・エネルギー種別）
- 月次集計・年次報告の自動生成
- SBTi目標に対する進捗率表示
- エコ・ファーストの約束に基づく目標管理

#### 2.4.2 産業廃棄物管理

##### マニフェスト管理
| 項目 | 説明 |
|------|------|
| 交付番号 | マニフェスト伝票番号 |
| 排出事業場 | 現場名・住所 |
| 廃棄物種類 | 汚泥/がれき類/廃プラ/木くず等 |
| 数量 | 重量（トン）・体積（m³） |
| 収集運搬業者 | 業者名・許可番号 |
| 処分業者 | 業者名・許可番号・処分方法 |
| 交付日 | マニフェスト交付日 |
| 返送状況 | B2/D/E票の返送確認 |

##### 電子マニフェスト対応
- JWNET（日本産業廃棄物処理振興センター）との連携
- 電子マニフェストの登録・確認・報告
- 返送期限の管理とアラート
- 年次報告書の自動生成

#### 2.4.3 その他環境管理
- 騒音・振動の測定記録管理
- 水質汚濁防止の記録管理
- 特定建設資材のリサイクル管理（建設リサイクル法）
- グリーン購入の実績管理
- 環境影響評価書の管理

### 2.5 是正処置・予防処置（CAPA）管理

#### 2.5.1 統合CAPA管理
品質・安全・環境の各分野で発生した不適合に対する是正処置・予防処置を統合管理する。

| 管理項目 | 説明 |
|---------|------|
| CAPA番号 | 自動採番 |
| 発生源 | 内部監査/外部監査/顧客苦情/NCR/ヒヤリハット |
| 対象ISO規格 | ISO9001/14001/45001/複合 |
| 根本原因 | RCA（Root Cause Analysis）記録 |
| 是正処置 | 具体的な対策内容 |
| 担当者 | 実施責任者 |
| 期限 | 完了期限 |
| 有効性確認 | 対策効果の検証結果 |
| 完了判定 | 品質環境部による完了判定 |

#### 2.5.2 統計分析
- CAPA件数の推移（月次・年次）
- 発生源別の件数分析
- 期限内完了率の管理（目標：90%以上）
- 根本原因のパレート分析
- 再発率の管理
