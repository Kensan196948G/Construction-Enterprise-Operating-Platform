## 2. データベース設計

### 2.1 主要テーブル

#### t_near_miss（ヒヤリハット）
```sql
CREATE TABLE t_near_miss (
    near_miss_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    reporter_id         UUID,
    occurred_at         TIMESTAMPTZ NOT NULL,
    location            VARCHAR(200),
    description         TEXT NOT NULL,
    cause_analysis      JSONB,  -- 4M分析: Man/Machine/Media/Management
    risk_level          VARCHAR(10),  -- 'high'/'medium'/'low'
    corrective_action   TEXT,
    photo_ids           UUID[],
    status              VARCHAR(20) DEFAULT 'reported',
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_ky_activity（KY活動）
```sql
CREATE TABLE t_ky_activity (
    ky_id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    activity_date       DATE NOT NULL,
    work_content        VARCHAR(200),
    hazards             JSONB,  -- [{hazard, risk_rank, measure}]
    participants        JSONB,
    leader_id           UUID,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_accident（労災事故）
```sql
CREATE TABLE t_accident (
    accident_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    occurred_at         TIMESTAMPTZ NOT NULL,
    severity            VARCHAR(20),  -- 'fatal'/'serious'/'minor'/'first_aid'
    injury_type         VARCHAR(50),
    description         TEXT,
    root_cause          TEXT,
    corrective_actions  JSONB,
    lost_days           INT DEFAULT 0,
    reported_to         VARCHAR(100),  -- 労基署等
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_safety_patrol（安全パトロール）
```sql
CREATE TABLE t_safety_patrol (
    patrol_id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    patrol_date         DATE NOT NULL,
    inspector_id        UUID,
    checklist           JSONB,  -- [{item, result, comment, photo_id}]
    overall_rating      VARCHAR(10),  -- 'A'/'B'/'C'/'D'
    corrective_orders   JSONB,
    follow_up_date      DATE,
    status              VARCHAR(20) DEFAULT 'completed',
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_quality_record（品質記録）
```sql
CREATE TABLE t_quality_record (
    quality_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    record_type         VARCHAR(30),  -- 'inspection'/'test'/'ncr'/'capa'
    title               VARCHAR(200),
    description         TEXT,
    result              VARCHAR(20),  -- 'pass'/'fail'/'conditional'
    evidence_files      JSONB,
    inspector_id        UUID,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_iso_audit（ISO監査）
```sql
CREATE TABLE t_iso_audit (
    audit_id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    audit_type          VARCHAR(20),  -- 'internal'/'external'/'surveillance'
    iso_standard        VARCHAR(20),  -- 'ISO9001'/'ISO14001'/'ISO45001'
    audit_date          DATE,
    scope               TEXT,
    findings            JSONB,  -- [{finding_type, clause, description, severity}]
    lead_auditor        VARCHAR(100),
    status              VARCHAR(20) DEFAULT 'planned',
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_environmental_record（環境記録）
```sql
CREATE TABLE t_environmental_record (
    env_id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    record_type         VARCHAR(30),  -- 'co2'/'waste'/'noise'/'water'
    record_date         DATE,
    scope               VARCHAR(10),  -- 'scope1'/'scope2'/'scope3'
    quantity            DECIMAL(15,4),
    unit                VARCHAR(20),
    manifest_number     VARCHAR(30),  -- 産廃マニフェスト番号
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

## 4. AI映像解析設計

### 4.1 検知対象
| 検知項目 | モデル | 精度目標 |
|----------|--------|---------|
| ヘルメット未着用 | YOLOv8 | 95%以上 |
| 安全帯未着用 | YOLOv8 | 90%以上 |
| 立入禁止区域侵入 | YOLOv8 + Zone Detection | 95%以上 |
| 重機接触危険 | YOLOv8 + Distance Estimation | 85%以上 |

### 4.2 処理フロー
```
監視カメラ → RTSP Stream → Edge AI (NVIDIA Jetson)
                                    │
                              ┌─────┴─────┐
                              │ YOLOv8    │
                              │ 推論      │
                              └─────┬─────┘
                                    │
                              ┌─────┴─────┐
                              │ 危険検知   │ → アラート通知
                              └─────┬─────┘
                                    │
                              クラウドログ保存
```

## 5. 度数率・強度率自動計算
```python
# 度数率 = (死傷者数 / 延べ労働時間数) × 1,000,000
frequency_rate = (injuries / total_work_hours) * 1_000_000

# 強度率 = (労働損失日数 / 延べ労働時間数) × 1,000
severity_rate = (lost_days / total_work_hours) * 1_000
```
