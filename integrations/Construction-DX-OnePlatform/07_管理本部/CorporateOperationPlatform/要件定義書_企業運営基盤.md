---

## 1. 概要
### 1.1 目的
総務・経理・人事の管理業務を統合するプラットフォームを構築する。DeskNet's NEOとのワークフロー連携、電帳法・インボイス制度対応を含む。

---

## 2. 機能要件

### 2.1 人事機能
- FR-COP-001: 人材配置管理（プロジェクト×技術者マトリクス）
- FR-COP-002: 技能資格管理（資格取得・更新・有効期限）
- FR-COP-003: 教育訓練管理（受講履歴・計画）
- FR-COP-004: 健康診断管理（特殊健診含む）
- FR-COP-005: 労務管理（勤怠・残業・36協定）
- FR-COP-006: 建設キャリアアップシステム（CCUS）連携

### 2.2 経理機能
- FR-COP-010: 工事原価管理
- FR-COP-011: 支払管理（協力会社・資材）
- FR-COP-012: 電子帳簿保存法対応
- FR-COP-013: インボイス制度対応（適格請求書管理）
- FR-COP-014: 予算管理

### 2.3 総務機能
- FR-COP-020: 契約書管理（電子保管・検索）
- FR-COP-021: 車両管理（配車・車検・保険）
- FR-COP-022: 備品管理
- FR-COP-023: 稟議ワークフロー（DeskNet's NEO連携）
- FR-COP-024: ワークフローエンジン（Flask Workflow Engine連携）

---

## 3. 非機能要件
- NFR-COP-001: Entra ID SSO
- NFR-COP-002: DeskNet's NEO API連携
- NFR-COP-003: 電帳法要件（タイムスタンプ・検索要件）

---

## 4. 技術スタック

| レイヤー | 技術 |
|----------|------|
| フロントエンド | React + TypeScript |
| バックエンド | Python FastAPI + Flask Workflow Engine |
| データベース | PostgreSQL |
| ワークフロー | DeskNet's NEO連携 |
| 認証 | Entra ID + HENNGE SSO |

---

## 5. 統合要件
- 施工管理→原価データ受信、経営ダッシュボードへ財務データ提供
- 購買システムとの支払連携
- 統合データレイクへの人事・経理データETL
