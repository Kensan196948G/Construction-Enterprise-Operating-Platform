## 2. データベース設計

### 2.1 主要テーブル

#### t_project（工事マスタ）
```sql
CREATE TABLE t_project (
    project_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_code        VARCHAR(20) UNIQUE NOT NULL,
    project_name        VARCHAR(200) NOT NULL,
    client_org_id       UUID REFERENCES t_client_org(org_id),
    project_type        VARCHAR(50),  -- '公共' / '民間'
    contract_amount     BIGINT,
    start_date          DATE,
    end_date            DATE,
    branch_id           UUID REFERENCES t_branch(branch_id),
    status              VARCHAR(20) DEFAULT 'active',
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_monthly_kpi（月次KPI）
```sql
CREATE TABLE t_monthly_kpi (
    kpi_id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    fiscal_year         INT NOT NULL,
    fiscal_month        INT NOT NULL,
    department_id       UUID REFERENCES t_department(dept_id),
    kpi_type            VARCHAR(50) NOT NULL,
    target_value        DECIMAL(15,2),
    actual_value        DECIMAL(15,2),
    achievement_rate    DECIMAL(5,2),
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_monthly_kpi_period ON t_monthly_kpi(fiscal_year, fiscal_month);
```

#### t_cost_record（原価記録）
```sql
CREATE TABLE t_cost_record (
    cost_id             UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_project(project_id),
    cost_type           VARCHAR(20),  -- 'labor'/'material'/'subcontract'/'expense'
    budget_amount       BIGINT,
    actual_amount       BIGINT,
    record_date         DATE NOT NULL,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_safety_record（安全記録）
```sql
CREATE TABLE t_safety_record (
    safety_id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_project(project_id),
    record_type         VARCHAR(30),  -- 'accident'/'near_miss'/'patrol'
    severity            VARCHAR(10),
    description         TEXT,
    occurred_at         TIMESTAMPTZ NOT NULL,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

#### t_ai_prediction（AI予測結果）
```sql
CREATE TABLE t_ai_prediction (
    prediction_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID REFERENCES t_project(project_id),
    prediction_type     VARCHAR(30),  -- 'profit_decline'/'deficit'/'delay'/'shortage'
    risk_score          DECIMAL(5,2),
    confidence          DECIMAL(5,2),
    details             JSONB,
    predicted_at        TIMESTAMPTZ DEFAULT NOW()
);
```

### 2.2 ER図概要
```
t_project ──┬── t_cost_record
             ├── t_safety_record
             ├── t_progress_record
             └── t_ai_prediction

t_department ── t_monthly_kpi

t_branch ── t_project

t_client_org ── t_project
```

## 6. AI予測モデル設計

### 6.1 利益率低下予測モデル
- アルゴリズム: Gradient Boosting (XGBoost)
- 入力特徴量: 工種、契約金額、工期、発注者、原価進捗率、天候データ
- 出力: リスクスコア (0-100)
- 学習データ: 過去5年分の完成工事データ
- 再学習: 月次バッチ

### 6.2 工期遅延予測モデル
- アルゴリズム: Prophet (時系列) + Random Forest
- 入力: 工程進捗率、天候、労務投入量、資材納入状況
- 出力: 遅延確率 + 予測遅延日数
