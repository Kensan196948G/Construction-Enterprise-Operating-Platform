## 2. データベース設計

### t_vessel（船舶マスタ）
```sql
CREATE TABLE t_vessel (
    vessel_id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vessel_name         VARCHAR(100) NOT NULL,
    vessel_type         VARCHAR(50),  -- '起重機船'/'浚渫船'/'台船'/'曳船'/'作業船'
    gross_tonnage       DECIMAL(10,2),
    imo_number          VARCHAR(10),
    mmsi                VARCHAR(9),  -- AIS用
    status              VARCHAR(20) DEFAULT 'active',
    current_location    GEOMETRY(POINT, 4326),
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### t_vessel_position（位置履歴 - TimescaleDB）
```sql
CREATE TABLE t_vessel_position (
    time                TIMESTAMPTZ NOT NULL,
    vessel_id           UUID REFERENCES t_vessel(vessel_id),
    position            GEOMETRY(POINT, 4326),
    speed_knots         DECIMAL(5,1),
    heading             DECIMAL(5,1),
    source              VARCHAR(10)  -- 'AIS'/'GPS'
);
SELECT create_hypertable('t_vessel_position', 'time');
```

### t_vessel_maintenance（保守点検）
```sql
CREATE TABLE t_vessel_maintenance (
    maintenance_id      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vessel_id           UUID REFERENCES t_vessel(vessel_id),
    maintenance_type    VARCHAR(30),  -- 'scheduled'/'unscheduled'/'drydock'
    description         TEXT,
    scheduled_date      DATE,
    completed_date      DATE,
    cost                BIGINT,
    parts_used          JSONB,
    status              VARCHAR(20),
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### t_fuel_record（燃料記録）
```sql
CREATE TABLE t_fuel_record (
    fuel_id             UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vessel_id           UUID REFERENCES t_vessel(vessel_id),
    record_date         DATE,
    fuel_type           VARCHAR(20),
    quantity_liters     DECIMAL(10,2),
    cost                BIGINT,
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### t_dredging_record（浚渫記録）
```sql
CREATE TABLE t_dredging_record (
    dredging_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id          UUID,
    vessel_id           UUID REFERENCES t_vessel(vessel_id),
    record_date         DATE,
    dredge_area         GEOMETRY(POLYGON, 4326),
    volume_m3           DECIMAL(15,2),
    disposal_site       VARCHAR(200),
    depth_before        DECIMAL(6,2),
    depth_after         DECIMAL(6,2),
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

## 3. API設計

|----------|------|------|
