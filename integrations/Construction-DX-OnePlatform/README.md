# Construction DX One Platform

**Construction DX One Platform** は、建設会社の本社・支店・現場・経営・監査で使う情報を、ひとつのWeb画面に集約する全社DX基盤です。

現時点のWebUIは、画面確認・業務確認・監査観点の確認を目的とした**モック環境**です。案件名、金額、氏名、アラート、監査ログはダミーデータです。

## 🌐 どこから見るか

統合ポータルのURLは、機器起動時に自動で割り当てられます。

```text
http://<自動で割り当てられたIPアドレス>:<空きポート>/
```

実際に使うURLは、IT部門から案内されるURLを利用してください。社外から利用する場合は、会社指定のVPNや認証手順に従ってください。

## 🎯 誰のための画面か

| 閲覧対象 | 主な確認内容 |
| --- | --- |
| 🏢 本社・支店 | 部門別の状況、案件、購買、管理業務、全社アラート |
| 👷 現場施工管理者 | 工事進捗、日報、写真、安全状況、作業員数 |
| 🧪 土木建設技術者・研究者 | BIM/CIM、施工ナレッジ、技術データ、AI予測 |
| 📈 経営役員 | 受注高、利益率、手持工事高、ESG、リスク予兆 |
| 📋 監査法人・内部監査 | 操作ログ、証跡、権限変更、監査チェック項目 |

## 🧭 ポータルで見られる領域

```text
Construction DX One Platform
  ├─ 🏗️ 施工本部              工程・日報・写真・出来高
  ├─ 🛡️ 安全品質環境本部      ヒヤリハット・リスク・ISO
  ├─ 🤝 営業本部              入札・顧客・受注見込み
  ├─ 🧠 技術本部              BIM/CIM・技術ナレッジ
  ├─ 📦 購買部                資材・発注・協力会社
  ├─ 🚢 船舶                  船団・運航・燃料・保守
  ├─ 🏢 管理本部              人事・経理・承認
  ├─ 📊 経営企画              KPI・AI予測・ESG
  ├─ 🗄️ 統合データ基盤        データ連携・AIモデル
  ├─ 💻 IT-DX部門             システム稼働・セキュリティ
  └─ 📋 監査                  操作証跡・出力・検索
```

## ✅ このプロジェクトで確認したいこと

| 観点 | 確認内容 |
| --- | --- |
| 業務適合 | 現場、本社、支店、経営、監査の確認導線が自然か |
| 見える化 | 工事、受注、安全、購買、IT状況が一覧で把握できるか |
| 監査性 | 誰が、いつ、何を変更したかを追跡できるか |
| 意思決定 | 経営KPIやAI予測が判断材料として使えるか |
| 現場利用 | タブレット・現場端末でも読みやすい構成にできるか |
