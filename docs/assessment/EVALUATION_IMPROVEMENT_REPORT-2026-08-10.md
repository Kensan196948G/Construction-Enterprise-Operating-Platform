## 3. 強み（15 件以上）

1. ランタイム依存ゼロ（node:http + node:sqlite）で脆弱性面・保守面が小さい
2. Result 型・strict TS による例外を投げない設計
3. 改ざん検知ハッシュチェーン監査ログ
4. RBAC + テナント境界 + 非開示 404（IDOR 対策）
5. JWT + API キー + リフレッシュ失効
6. ISO 9001/14001/45001/55001/19650 の統合管理を 1 基盤で実装
7. IMS 互換エイリアス 32 系統で移行コスト低減
8. 連携先6システムの Webhook/イベント/再送/冪等性基盤
9. テスト 401 件 + parity 検証 + Playwright E2E の自動化
10. 日次バックアップ + VACUUM INTO + 復元実演済み
11. Prometheus/Grafana 監視スタック導入済み
12. バージョン一元管理（src/version.ts・package.json・Dockerfile 整合テスト）
13. 本番デプロイ済み（v0.11.0）で公開 URL 動作確認済み
14. 移行台帳・アーカイブ（git bundle・Issue/PR）整備
15. シークレットを Git へ保存しない運用（.env 分離・provision CLI）
16. AI ガバナンス（根拠・入力保持・PII・誤回答対策・利用停止）実装
17. 運用文書（RUNBOOK/BACKUP/MONITORING/LEDGER）が実運用と一致
