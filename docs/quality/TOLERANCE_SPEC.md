# 📏 Tolerance Specification

| ID         | 対象             | 判定                                          | 根拠                                                               |
| ---------- | ---------------- | --------------------------------------------- | ------------------------------------------------------------------ |
| QA-TOL-001 | 発注金額・労務費 | `abs(actual - expected) <= fixture.tolerance` | 円の整数計算は0、少数入力はfixtureに明示した浮動小数点誤差のみ許容 |

Toleranceはテストを通すために後から広げません。業務単位、丸め規則、法令・契約上の精度が変わる場合は、仕様変更としてこの文書、Golden Dataset version、期待値を同時にレビューします。相対Toleranceが必要な大規模数値を導入する場合は別IDを作り、絶対Toleranceと混在させません。

現在の実装は入力値を丸めずJavaScript numberで計算します。通貨の丸め方式が業務仕様として確定した場合は、計算エンジンを整数最小単位またはdecimal表現へ移行し、移行前後のGolden Regressionを必須とします。
