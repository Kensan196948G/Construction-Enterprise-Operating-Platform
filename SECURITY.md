# Security Policy

## Supported Versions

Security updates are provided for the latest `main` release (currently v0.12.x).

## Reporting a Vulnerability

This is a private repository. Please report suspected vulnerabilities privately
to the repository owner via GitHub's private vulnerability reporting or a
private issue, and do not include credentials or personal data in the report.

Include:

- affected version / commit
- steps to reproduce
- impact assessment
- suggested fix (optional)

The platform team will acknowledge within 5 business days and provide a fix
timeline based on severity.
